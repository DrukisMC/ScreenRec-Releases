# ScreenRec-Releases

Public release channel for **ScreenRec** (in-game screen recorder for
Minecraft Bedrock, LeviLauncher mod). Binaries only; source is private.

- Import the `.levipack` from the latest Release in LeviLauncher.
- ModMenu → **Recording** ON/OFF. Clips land in
  `mods/ScreenRec/records/`.
- Minecraft 1.26.50.
